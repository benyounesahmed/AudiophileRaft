## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/AudiophileRaft.git`
2. `cd AudiophileRaft`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure AudiophileRaft, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
